# Change log

## V5 · Module-level learning and Apple-inspired interface

- Changed course knowledge structure to exactly two knowledge levels: first-level modules and checkable second-level points.
- 65 courses, 262 modules, 808 points. Reorganized Calculus into six major topics.
- Added automatically computed module, course, major and all-course progress bars.
- New responsive interface with glass-like surfaces, light/dark mode, collapsible cards, knowledge graph and dedicated note inspector.
- Preserved all capstone and robot-module GitHub references.
- Added backup export/import and migration of V4 progress and custom notes.
- No build step, backend or runtime CDN dependency; deploy from `docs/` using GitHub Pages.
