# 实施顺序：先跑通第一代机器人，再扩展具身大脑

> 每阶段建议 3～4 门核心课并行，避免同时开 65 个大项目。

## 阶段 A：0→1 的第一台机器人（优先）
1. Python/C++ 程序设计：机器人驱动 API；
2. 机器人运动学 + 线性代数：麦克纳姆正逆运动学；
3. Linux + ROS 2：控制节点、Topic、TF；
4. 电路原理 + MCU：供电、PWM 和传感器采样；
5. 计算机视觉：视觉跟随；
6. 数据结构与算法：A* 迷宫；
7. 机器人仿真：Gazebo 数字孪生。

## 阶段 B：让机器人自主完成任务
1. 概率统计、传感器融合、控制原理；
2. 导航 / SLAM，具备硬件条件后进行实机导航；
3. NLP 与 Agent：语音指令→任务树→机器人动作；
4. 边缘部署、日志与异常恢复。

## 阶段 C：第二代移动操作机器人
机械 CAD + PCB + MCU + 机械臂运动学 + MoveIt 2 + 仿真与实机测试。

## 阶段 D：具身学习与科研
强化学习、模仿学习、LeRobot、Diffusion Policy、VLA 和实验基线对比。

### 硬件边界
当前树莓派 4B/麦克纳姆车用于第一阶段。没有编码器不能只靠 PWM 断言已实现轮速闭环；视觉/激光 SLAM 必须按照传感器配置做适配。

### 每个项目的质量门槛
有源码、可复现环境、数据指标、演示视频和自己写的技术分析；不是只运行开源代码。
