# V5 知识模块与进度管理操作指南

## 1. 固定层级

专业 → 专业课程 → 一级知识模块 → 二级知识点（Check）

系统已为全部 65 门课程配置共 262 个一级模块、808 个二级知识点。一级模块是知识主题，例如高等数学的“一元函数微分学”；二级知识点是可以独立验收的知识，例如“导数与微分”“微分中值定理”。不建议继续在知识点下面增加第三层；需要细分时，可以将原知识点改成更具体的多个二级知识点。

## 2. 完成率怎么计算？

- 一级模块 = 该模块已勾选二级知识点数 ÷ 该模块二级知识点总数。
- 专业课程 = 该课程所有一级模块下已勾选知识点总数 ÷ 该课程二级知识点总数。
- 专业领域 = 该专业所有课程的已勾选知识点总数 ÷ 该专业二级知识点总数。
- 总进度 = 10 个专业的已勾选二级知识点总数 ÷ 所有二级知识点总数。

所有百分比在界面中四舍五入为整数。空模块不计入分母，显示为 0%。

## 3. 典型学习流程

1. 从左侧点开一个专业，再选择一门课程。
2. 查看课程中的一级模块进度，点击模块卡片展开知识点。
3. 学完一个二级知识点后点击左侧圆形 Check，模块和课程进度立即更新。
4. 点击二级知识点的标题，在右侧填写个人笔记、练习心得及学习资源链接；点击“保存笔记与资料”。
5. 想看到图谱时切换“知识图谱”标签，点击一级模块展开相关知识点；可拖动画布、滚轮缩放和勾选叶节点。
6. 切换“项目实践”查看本门课程的趣味结课大项目、机器人模块项目与 GitHub 参考。
7. 按需要新增/改名/删除一级模块及二级知识点。界面上的编辑只保存在当前浏览器。

## 4. 本地存储与备份

浏览器 localStorage 存储键：`embodied-atlas-v5`。数据包括 `completed`（勾选状态）、`overrides`（自定义课程模块）、`notes`（笔记与资源）。关闭标签页后一般保留，但清除网站数据、无痕模式或更换浏览器可能导致记录丢失。

右上角向下箭头用于导出备份 JSON；向上箭头用于导入。**导入会覆盖当前学习记录，请先备份。** GitHub Pages 只托管静态网页，不负责自动同步个人学习进度。

V5 兼容导入 V4 导出的 `embodied-ai-fullstack-progress` 格式 JSON；V4 三态进度中的 `done` 会转换成 Check 完成，另外两种状态不会被计入完成度。V4 的多层嵌套目录在导入时自动规范成“一级模块 → 二级知识点”，必要时使用“父级 · 子项”前缀保留原知识主题。

## 5. 同步给 GitHub Pages 的默认课程目录

如果希望**每一位访问网站的用户**看到的初始知识模块发生变化，编辑 `data/course_topics.json`。其结构为：

```json
{
  "version": "5.0",
  "courses": {
    "01-01": [
      {
        "id": "01-01-module-unique-id",
        "title": "一元函数微分学",
        "children": [
          { "id": "01-01-point-unique-id", "title": "导数与微分", "children": [] }
        ]
      }
    ]
  }
}
```

编辑后运行：

```bash
python scripts/sync_graph.py
```

然后将 `data/course_topics.json`、`docs/topics.js` 等文件提交并推送到 GitHub，Pages 将重新部署。请保证同一课程的模块 ID 和知识点 ID 唯一；不要频繁更改已有知识点 ID，因为 Check 状态以 ID 为键保存。

## 6. 设计与安全说明

页面使用系统字体、响应式布局、轻量图谱绘制和可切换深浅色主题，没有依赖第三方 CDN。学分、证书和“掌握程度”不会被简单地从勾选中推断；Check 仅是个人标记，建议结合练习、代码实现或项目评测验证实际掌握情况。
